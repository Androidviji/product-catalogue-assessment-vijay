## Stage 1: backend foundation

Decisions made during the build, with evidence:

- **Spring Boot 4.1.2.** Spring Initializr (checked live) only offered 4.x versions, so the AI used
  the current stable release. The project skeleton and Maven wrapper were generated by Initializr
  rather than written from memory, because Boot 4 changed starter names (`spring-boot-starter-webmvc`)
  and test packages (`org.springframework.boot.webmvc.test.autoconfigure`).
- **Fetch the full product list once, not one request per featured ID.** A live check showed Fake Store
  returns `HTTP 200` with an empty body for an unknown ID (`/products/999`), not a 404. Fetching the list
  (20 products) and looking IDs up locally makes "missing" unambiguous and needs one call instead of five.
- **Missing featured product policy.** Return the found products in configured order, list the missing
  IDs in `missingProductIds`, include `configuredCount`, and log a warning. The response never implies
  that all five were found.
- **Configuration is checked at startup.** An empty or duplicated `featured-product-ids` list stops
  the app from starting, so the mistake is caught before customers see it.
- **Three product shapes on purpose:** Fake Store JSON (private to `FakeStoreProductSource`) maps to our
  `Product`, which maps to `ProductResponse` (the API contract). `Product` keeps the source image URL
  internally for the later image endpoint; `ProductResponse` does not expose it.
- **Timeouts:** 3s connect, 5s read, configured on the JDK `HttpClient` request factory. There is a test that
  proves a server that never replies produces a 503-style failure in under 3 seconds.
- **Errors:** a 503 RFC 9457 problem response with `code: PRODUCT_SOURCE_UNAVAILABLE`. The full exception
  is logged on the server only. A test checks that the response body does not contain the internal message.
- **Mailpit pinned to `v1.33.1`**, not `latest` or the two-day-old `v1.34.0`. Ports are bound to `127.0.0.1`.
- **Left out for now:** the validation starter (no request input yet), caching of the product list,
  and category or search endpoints.
